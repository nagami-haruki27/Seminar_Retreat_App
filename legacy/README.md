# 人力Semantle

## 準備（合宿前に1回）
```bash
pip install -r requirements.txt
streamlit run app.py
```
初回の起動時にモデル（ME5）がダウンロードされるので、**宿に行く前に一度起動しておいてください**（baseで約1GB）。

## 遊び方
1. 左側のサイドバーで、ルール・チーム数・チーム名を設定する
2. 司会がお題を入力する（例：拡散モデル）
3. 各チームで相談して単語を1つ決め、代表者が前に出て入力する（またはホワイトボードに書いて司会が入力）
4. 「判定！」を押すと、順位・スコア・棒グラフが表示される。1位に3点、2位に2点、3位に1点が加算される

## ルール
- **① 最も似ている単語**：スコアが一番高いチームの勝ち
- **② 目標値ぴったり**：スコアが目標値（デフォルト0.5）に一番近いチームの勝ち
- お題そのもの、またはお題を含む単語・お題に含まれる単語は反則（順位なし）

## 補正スコアについて
E5は異方性があるため、無関係な単語同士でも類似度が0.7〜0.8程度になります（2024年のM2クイズの付録にもあった現象です）。
そのため、`core.py` にある60個の一般的な単語とお題との平均類似度を0、お題そのものを1とする線形変換をかけています。
②のルールで遊ぶときは、補正をオンにしておかないと「0.5」がほぼ出ません。

## お題の例
- 研究系：拡散モデル、推薦システム、過学習、査読、締切、強化学習
- 研究室系：ゼミ、先生、合宿、研究室の名前
- 一般：冬、温泉、カレー、雪
